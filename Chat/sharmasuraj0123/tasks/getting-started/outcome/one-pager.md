# Getting started with quirq

quirq is a filesystem-first workspace. Files hold the content and open-chat shows it, so changing a file changes what you see.

## How work flows

1. **Set a goal.** Each task lives in `Chat/<username>/tasks/<task-name>/`. Its README states the goal and picks one output format: Slides, One pager, Website, or GitHub URL.
2. **Talk it through.** Conversations about the task are saved in the task's `chats/` folder.
3. **Get the outcome.** Claude reads the goal and the chats, then writes the result to `outcome/` in the chosen format.

## The other places

- **Activity** records what happened.
- **Insights** keeps the observations worth returning to.
- **Vision** holds the direction behind the work.
- **Library** saves links to outside pages.
