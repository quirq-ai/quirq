# quirq-ai wiki

## Owner

euler

## Input

A wiki of the quirq-ai GitHub organization: one sub-channel per repository, public and private, each holding a one-page summary of that repo (purpose, stack, structure, how to run it, status and key links). This channel's output is the index that links every one-pager, grouped by what the repos are for. Add a sub-channel when a new repo appears, and regenerate a page when its repo changes.

## Output format

One pager
